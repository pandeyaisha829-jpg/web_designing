CSS background-repeat & Link Styles

1) The background-repeat property

background-repeat: repeat (both directions)
background-repeat: repeat-x (horizontal only)
background-repeat: repeat-y (vertical only)
background-repeat: no-repeat (shown once)

2) Styles for links

Pseudo-class Meaning Style Applied
A:link Normal, unvisited link Blue, no underline
A:visited Link already visited by the user Purple, no underline
A:hover Mouse pointer is over the link Red, underline, yellow background
A:active Link at the moment it is clicked Green, underline overline
