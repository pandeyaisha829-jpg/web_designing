CSS Cascading Style Sheets

1) Different fonts and styles

This paragraph uses the class selector ".fancy" (Times New Roman, bold, italic, purple).

This paragraph uses the class selector ".plain" (Verdana, 14px, line-height 24px, justified). In the style definition we define how each selector should work (font, color etc.). Then, in the body of the page, we refer to these selectors to activate the styles.

This paragraph uses the ID selector "#special" (Courier New, uppercase, white text on dark blue).


Selector Type Property Used
h1, h2 Element selector font-family, color, font-size
.fancy, .plain Class selector font-style, font-weight, line-height
#special, #box ID selector text-transform, background-image
